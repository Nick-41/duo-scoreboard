Safari 실행 방식별 테스트

아래 후보를 하나씩 눌러 Safari로 전환되는지 확인하세요. 브라우저가 자체적으로 외부 앱 호출을 막을 수 있습니다. 테스트용으로만 만든 페이지입니다.

1. Safari 전용 URL 링크Safari 스킴 링크사용자 탭으로 x-safari-https:// 이동
2. Safari 전용 URL 스크립트사용자 탭으로 외부 앱 URL 실행
3. 새 창으로 Safari 요청새 창 허용 여부에 영향을 받을 수 있음
4. 과거 Safari URL 형식기존 Safari 스킴 링크com-apple-mobilesafari-tab: 방식
5. 일반 새 탭 링크(대조군)HTTPS target=_blank이 방식은 Safari를 지정하지 않음
