# Duo Hub · 듀오 허브

아이폰 듀오의 접힌 화면·펼친 화면과 PC에서 사용하는 **개인용 웹 도구 허브**입니다.

## 제공 도구
- **점수판** — 2~4팀, 팀 이름과 점수 자동 저장, 되돌리기
- **대형 글씨** — 문구 입력, 크기·배경 설정, 화면 가득 표시
- **타이머 · 스톱워치** — 프리셋, 일시 정지, 초기화, 경과 시간 추적
- **공간 배치 스튜디오** — 추가 예정 (현재 미연결)

## 구조
- \`index.html\`: 홈 / 검색·카테고리·즐겨찾기·테마 전환
- \`tools/scoreboard.html\`: 기존 점수판 기능 유지
- \`tools/bigtext.html\`: 대형 글씨
- \`tools/timer.html\`: 타이머 / 스톱워치
- \`manifest.webmanifest\`, \`assets/icon.svg\`: 설치형 웹사이트 메타데이터

## 새 도구 추가
1. \`tools/\` 폴더에 단일 HTML 파일을 추가합니다.
2. \`index.html\`의 \`tools\` 목록에 항목을 추가합니다.
3. \`path\`에 상대 경로, \`ready: true\`를 지정합니다.

서버 및 외부 라이브러리를 사용하지 않습니다. 점수, 즐겨찾기, 설정은 브라우저의 로컬 저장소에 저장됩니다. 인터넷 연결이 끊기면 초기 실행이 어려울 수 있고, 브라우저 데이터 삭제 시 설정이 사라질 수 있습니다.

**주의:** 저장소 이름 \`duo-scoreboard\`는 기존 GitHub Pages 주소 및 홈 화면 바로가기와의 호환성을 위해 유지하고, 화면에 표시되는 서비스 이름을 \`Duo Hub\`로 변경했습니다.
