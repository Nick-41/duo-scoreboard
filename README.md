# 모아덱 MoaDeck

점수판, 타이머, 동전과 주사위, 공간 배치 등 필요한 웹 도구를 한곳에 모았습니다. 아이폰의 접힌 화면과 펼친 화면, PC 브라우저에서 이용할 수 있습니다.

[모아덱 열기](https://nick-41.github.io/moadeck/)

## 도구

| 도구 | 주요 기능 |
| --- | --- |
| [점수판](tools/scoreboard.html) | 2~4팀, 팀 이름과 점수 자동 저장, 실행 취소 |
| [대형 글씨](tools/bigtext.html) | 글자 크기와 배경 선택, 전체 화면 표시, 두 번 탭하여 편집으로 복귀 |
| [타이머 · 스톱워치](tools/timer.html) | 카운트다운, 경과 시간 측정, 프리셋, 일시 정지 |
| [동전 · 주사위](tools/chance.html) | 한 번에 1~20개, 동전 뒤집기·주사위 굴리기 효과, 결과 합계 |
| [룰렛](tools/roulette.html) | 2~12개 항목, 회전 애니메이션과 당첨 결과 |
| [구슬 레이스](tools/marble-race.html) | 한 기기에서 2~32명 참가, 코스 4종, 실시간 순위, 전체화면과 관전 카메라 |
| [제비뽑기](tools/lots.html) | 2~24장, A·B·C 기본 이름, 직접 선택 또는 무작위 선택, 뒤집기 효과 |
| [멀티카운터](tools/counters.html) | 항목별 수량, 합계, 실행 취소와 자동 저장 |
| [투표판](tools/vote.html) | 한 기기에서 득표수·득표율 집계, 실행 취소와 자동 저장 |
| [공간 배치 스튜디오](space-studio/index.html) | 전체 보기·너비 맞춤, 위치와 크기 수치 편집, 5cm 정렬과 백업·복원 |

## 이용 방법

- 홈에서 검색하거나 분류를 선택하세요. 카드의 별표를 누르면 즐겨찾기에 추가됩니다.
- iPhone Safari에서 공유 메뉴의 **홈 화면에 추가**를 선택하면 모아덱 아이콘으로 바로 열 수 있습니다.
- 점수와 설정은 현재 브라우저에 저장됩니다. 브라우저 데이터를 지우면 저장된 설정이 사라질 수 있습니다.

## 도구 추가

도구 HTML을 `tools/`에 넣고 `index.html`의 `tools` 목록에 이름, 설명, 분류와 상대 경로를 등록합니다. 저장소의 `main` 브랜치가 GitHub Pages에 배포됩니다.
